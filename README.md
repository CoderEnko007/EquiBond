# EquiBond · 股债性价比系统

> 📘 **完整项目文档（模块原理 / 使用说明 / 数据更新 / 扩展开发 / FAQ）请见网页版 [`PROJECT.html`](PROJECT.html)**（由 `PROJECT.md` 生成，改 MD 后运行 `python scripts/md2html.py` 重新生成）
> 本文件是快速上手用的简版。

把"一分钟宏观模型 —— 投资回报 VS 债券利息"工程化成一个可交互、可回测、可复现的股债配置系统。

核心只有一个式子：

```
股权风险溢价 ERP = 盈利收益率 E/P − 10年期国债收益率 Y10
                 = 100 / PE(TTM) − Y10
```

ERP 越大 → 承担股票风险得到的补偿越厚 → 越该超配股票；
ERP 收窄甚至转负 → 债券的确定性收益更有吸引力 → 该减股票。

## 快速开始

**双击 `start.bat`** —— 它会自动联网补齐最新交易日数据、重建数据集，然后打开页面。
（只用 Python 标准库，无需安装任何第三方包，也不挑 Python 版本。）

只想看历史数据、不联网的话，直接双击 `index.html` 也行（数据以脚本形式内嵌，`file://` 下可跑）。

## 数据自动更新机制

### 能自动拿到什么

| 字段 | 自动更新 | 来源与方法 |
|---|---|---|
| 沪深300 收盘价 | ✅ 每交易日 | 新浪 / 东财双源交叉校验 |
| PE / PB / 股息率 | ✅ 推算 | 见下方「滚动推算」 |
| 10年期国债 YTM | ❌ 手动 | **没有稳定的免鉴权免费接口**，见「为什么不自动」 |

### PE 的滚动推算为什么是准的

在同一份财报的有效期内，指数盈利 `E` 不变，而 `PE = P / E`，于是：

```
PE_today   = PE_anchor × (Close_today / Close_anchor)
PB_today   = PB_anchor × (Close_today / Close_anchor)
股息率_today = 股息率_anchor × (Close_anchor / Close_today)   # 分红金额固定，随价格反向
```

这在两个财报之间是**数学恒等**，不是估算。脚本会从 CSV 末行读锚点，永远从锚点起算（不逐次叠加漂移）。

**但跨过财报披露期后 E 会跳变**（沪深300 大致在 4 月底 / 8 月底 / 10 月底），此时推算失真。
脚本会把上次「权威校准」的日期记在 `data/raw/calibration.json`，超过 **110 天**就在运行时警告，
同时在页面顶部弹出红色提示条。届时：

- 在 WorkBuddy 里对我说 **「校准股债数据」**，我用 Wind MCP 重新取一次 PE/PB/股息率；
- 或手工改写 `hs300_valuation_monthly.csv` 末行后运行 `python scripts/update.py --calibrate`。

### 为什么要 `--calibrate` 单独认一次

脚本自己每天更新时不能刷新锚点日期，否则「距今多少天」永远归零，过期检查就永远命中不了。
`--calibrate` 是唯一会改动 `calibration.json` 的开关，语义就是「这次是权威源」。

### 国债收益率现在自动了

2026-10-27 起，`scripts/update.py` 用**东方财富的「中债国债收益率曲线」接口**自动取 10Y（免鉴权、日频），
原来的中国货币网接口已失效（404），保留在 `YIELD_SOURCES` 里仅作兜底。

唯一限制：**当日曲线一般 17:30 之后才发布**，白天运行拿到的是上一交易日，脚本末尾会标注实际取值日期。
所以想拿当天数据，最好收盘后（18:00 以后）再跑一次 `start.bat`。

再加新源：往 `YIELD_SOURCES` 里注册一个返回 `{date, y10}` 的函数即可，其余代码不用动。

### 页面上的状态提示

右上角显示 `最新数据点 YYYY-MM-DD ｜ 最新/滞后/过期 N 天 ｜ 国债YTM 取自 YYYY-MM-DD`；
出现以下任一情况时，页面顶部会弹提示条（点 × 关闭）：

- 数据超过 8 天没更新 → 提示双击 `start.bat`
- PE 锚点超过 110 天 → 红色警告，提示需要用 Wind 重新校准
- 上次运行没联网成功 → 提示当前显示的是历史快照

## 手动更新数据（不走自动脚本时）

数据按月更新即可（信号本身是月频的）：

1. 往 `data/raw/hs300_valuation_monthly.csv` 追加一行当月末的
   `date,pe,pb,div`（沪深300 月末最后交易日，口径：指数加权）；
2. 往 `data/raw/hs300_price_monthly.csv` 追加 `date,close`；
3. 往 `data/raw/cgb_yield_daily.csv` 追加当月 `date,y10,y1,y30`；
4. 重跑 `python scripts/build_dataset.py`，前端刷新即可。

当前样本：**2012-01 ~ 2026-10，共 178 个月**。

## 模型细节

### 信号 → 仓位

绝对值没有意义，**相对自身历史的位置**才有意义：

| 步骤 | 做法 |
|---|---|
| 1. 标准化 | 用回看窗口（默认近 10 年）内的历史分位，或 Z-Score |
| 2. 映射 | 线性映射到仓位区间（默认股票 20% ~ 90%） |
| 3. 调仓 | 按月 / 季 / 半年再平衡，每次换手收取成本（默认 5bp） |
| 4. 防未来函数 | 只允许用 `t−1` 期信号决定 `t` 期仓位 |

三种信号口径：**差值式 ERP**（最直观）、**比值式 E/P÷Y10**（利率极低时更敏感）、**股息式 股息率−Y10**（最保守）。

### 买卖信号（沪深300 上的 ▲▼ 标记）

页面「沪深300 买卖信号」板块把模型信号落成具体买卖时点：

- **买入**：信号分位 ≥ 65%（估值给方向即动手，不等趋势）；
- **卖出**：信号分位 ≤ 35% 且收盘跌破 60 日线（趋势确认，避免估值预警后过早离场——
  2015-01 纯估值会卖在 3534，加确认后 2015-06 卖在 4473）；
- 月末评估、次月执行，与回测同口径；附成交量情绪（20 日对数成交量 z-score）作辅助判读；
- 组合对照回测数据见 `scripts/combo*_test.js`，规则实现见 `engine.js` 的 `tradeSignals`。

### 收益率合成

- 股票端：沪深300 价格收益 + 上月股息率/12（总收益近似）；
- 债券端：`r ≈ carry − D_mod × Δy`，其中 `D_mod` 是 10 年期平价国债的修正久期，
  已包含票息与利率变动带来的资本利得，可覆盖全样本。

## 已知局限

- 使用 TTM 盈利，盈利有周期性，低 PE 可能是盈利处于高位造成的假象；
- 样本仅 2012 年以来，且 A 股估值中枢本身在下移，历史分位会系统性偏高；
- 债券端为合成的固定期限指数，未考虑信用利差与骑乘收益；
- 模型只回答**股债之间的相对配置**，不预测短期涨跌，不替代个股选择；
- 历史回测不代表未来表现。
